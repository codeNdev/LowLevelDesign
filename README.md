## 🧩 What's Included

### ✅ Design Patterns
- **Decorator Pattern**: Add responsibilities to objects dynamically.
- **Factory Pattern**: Encapsulate object creation logic.
- **Observer Pattern**: One-to-many dependency handling.
- **Strategy Pattern**: Encapsulate algorithms and make them interchangeable.

### 🎮 Design Problems
- **Tic Tac Toe**: 2-player grid-based game design.
- **Chess Game**: Full system design for chess.
- **Movie Ticket Booking System**: Multiplex ticket booking workflow.
- **Parking Lot Design**: Real-world system modeling of a parking lot.
- **Snake and Ladder Game**: Dice game implementation with multiple players.

## 🚀 Getting Started

### Prerequisites
- Java 8 or higher
- IntelliJ IDEA or any Java IDE

### Running the Code

Each problem is structured with its own package. Use `Main.java` or individual problem-specific `main` classes to run the demos.
